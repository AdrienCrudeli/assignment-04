Why are we using clamp instead of media queries?
We use clamp because it makes text resize smoothly between a minimum and a maximum size without writing extra breakpoints.

Why did we use minmax instead of fixed columns?
We use minmax because the grid can adapt to different screen sizes. Fixed columns are more rigid and can break more easily on small screens.

Why is it important to implement a mobile-first website?
Mobile-first is important because it starts with the simplest layout, works better on small screens, and is easier to scale up for larger screens.

What happens if we remove the variables that were defined at the beginning?
If we remove the variables, the design becomes harder to maintain. We would need to repeat colors, spacing, and sizes everywhere, and updates would take more time.
